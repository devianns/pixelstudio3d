# Dahlia · v4

v3에 머리 파트의 공통 기울기를 적용하고, 오른쪽 날개를 위로 들어 비대칭 실루엣을 만들며, 양쪽으로 흩날리는 긴 머리카락 곡선 가닥을 추가한 단계입니다.

- `model.json`: 프로젝트 형식 v1, 79개 파트
- `reference/angel-pixel-reference.png`: 기존 보관 에셋에서 가져온 비교용 유사 이미지. 이번 대화 원본과 동일한 파일은 아님
- `studio-preview.png`: 브라우저 실행 캡처
- `../build-v4.ps1`: v3에서 v4를 재생성하는 버전 빌더
- 전역 head group 기능 없이 개별 head 파트의 좌표와 회전을 함께 변환하여 한쪽으로 기울였습니다.

얼굴·날개·머리카락 실루엣이 이전 버전보다 비대칭적으로 되어 원화의 동적인 인상에 가까워졌습니다. 아직 원화의 정확한 시점과 옷 주름, 얼굴 3/4 방향은 재구성하지 못했습니다.
