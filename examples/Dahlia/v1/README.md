# Dahlia · v1

## 참조

`reference/angel-pixel-reference.png`는 사용자가 이번 대화에서 올린 원본 파일이 아니라, 기존 로컬 에셋 `SubProjects/private-image-assets-saver/generated/pixel-art-previews/celestial-angel-chibi-v2-preview.png`에서 가져온 가장 유사한 보관 이미지입니다. 흰색/은색 장발, 청록색 포인트, 별 장식, 후광, 천사 날개와 파란색/흰색 의상 형태를 참고한 대체 레퍼런스입니다. 원본 Dahlia 이미지 파일을 받으면 이 파일을 덮어쓰지 말고 `reference/original-dahlia.png`로 추가하고 이 기록을 갱신합니다.

## 결과 모델

- `model.json`: Pixel Studio 3D 프로젝트 형식 v1
- `studio-preview.png`: 로컬 브라우저에서 모델과 참조 오버레이를 함께 띄운 실행 화면 캡처
- 전면(+Z) 기준, Y-up
- 얼굴/눈/동공, 은백색 머리와 앞머리/긴 옆머리, 청록 머리 포인트, 별 장식, 금빛 후광, 좌우 날개 윤곽/깃, 상의/치마/앞치마, 소매, 다리와 부츠를 3D 메시 파트로 나눴습니다.
- 기본 도형(구, 토러스)과 `polygon` extrude 윤곽 메시를 조합한 3D 블록아웃이며, 원화의 비스듬한 포즈와 의상 주름을 정확하게 재구성한 완성 조각 모델은 아닙니다.
- 깊이(Z), 파트 겹침, 날개 실루엣, 앞머리 곡면은 스튜디오에서 불러온 뒤 직접 보정하거나 AI JSON 명령으로 반복 수정할 대상입니다.

스튜디오에서 왼쪽 패널의 **Dahlia v1 열기** 버튼을 누르면 JSON과 레퍼런스 오버레이가 함께 열립니다. 레퍼런스는 모델 파일에 임베드되지 않으며 `reference/` 경로의 이미지로 읽습니다.
