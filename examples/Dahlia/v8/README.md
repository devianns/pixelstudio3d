# Dahlia v8 — volumetric low-poly character pass

This version replaces the shallow v7 front-plate construction with closed cross-section volumes for the head, back hair, torso, skirt, arms, legs and wing roots. Face accents, bangs and feather silhouettes remain authored triangle surfaces. All scene geometry is `type: "mesh"`; no built-in sphere/cylinder/cone primitives are used.

The reference is the existing local angel pixel-art proxy, not the exact attached illustration (that source file was unavailable in the workspace). Load with **Dahlia v8 volumetric mesh** or `?example=Dahlia-v8`. Use the front, side and back camera buttons to review depth. This is a cartoon blockout proving the volume contract, not a finished avatar or exact 2D reconstruction.
