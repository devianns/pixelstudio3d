# Dahlia · v3

v2를 바탕으로 포즈와 전경 레이어를 보정한 단계입니다.

- `model.json`: 프로젝트 형식 v1, 72개 파트
- `reference/angel-pixel-reference.png`: 버전 비교를 위해 유지한 유사 보관 레퍼런스. 원본 Dahlia 이미지가 아님
- `studio-preview.png`: 브라우저 실행 캡처
- 앞쪽으로 나온 앉은 허벅지, 가슴 앞 교차 소매, 손, 눈 흰자/홍채 레이어, 부츠 디테일을 추가했습니다.
- 모델의 파트는 각각 편집 가능하지만 아직 서로 부모/자식으로 묶이지 않습니다. 움직이는 포즈를 만들 때는 그룹/리깅 기능이 필요합니다.
- 스튜디오의 `Dahlia v3 열기`로 불러옵니다.

v3는 원본 일러스트의 완전 재현이 아니라 형태를 파악하기 위한 low-poly stylized blockout입니다. 특히 얼굴 기울기, 긴 웨이브 머리, 접힌 천 주름, 다리의 원근은 추가 조형이 필요합니다.
