# Dahlia · v5

v4의 파츠 조립을 바탕으로 볼륨 조형과 카툰 셰이딩을 시험하는 단계입니다.

- `model.json`: Pixel Studio 3D 프로젝트 v1, 77개 파트
- `settings.renderStyle = "toon"`: 3단계 셀 셰이딩
- `settings.floorY = -1.4`: 캐릭터 발 아래로 미리보기 격자를 이동
- `loft` 단면 볼륨: 몸통과 플레어 치마의 단면을 여러 높이에서 조절
- 가변 반지름 `curve`: 소매와 다리의 시작/끝 굵기를 바꾸어 테이퍼된 팔다리 형태 생성
- `reference/angel-pixel-reference.png`: 이전 버전과 같은 보관용 유사 레퍼런스이며 새 대화 원본은 아님
- 스튜디오의 **Dahlia v5 열기**로 불러옵니다. 모델 설정에서 부드러운 음영/카툰 셀 셰이딩을 직접 전환할 수도 있습니다.
- `studio-preview.png`: 웹 스튜디오에서 v5를 불러온 화면 캡처

이 버전은 모양이 구·평면 파츠로 분절되어 보이던 문제를 줄이기 위한 구조 실험입니다. 아직 손가락·관절·연결된 스킨, UV/텍스처, 본 리깅, 정교한 얼굴 표정은 구현되지 않았고, 현재 렌더 스타일은 재질별 색 덩어리 중심의 카툰 음영입니다.
