# 예제 모델 아카이브

캐릭터별로 디렉터리를 나누고, 각 버전마다 참조 이미지와 `pixel-studio-3d-project` JSON, 제작 메모를 함께 보관합니다. 완성본을 덮어쓰지 말고 수정할 때는 `v2`, `v3` 폴더를 추가합니다.

```text
examples/
  README.md
  Dahlia/
    v1/
      README.md
      model.json
      studio-preview.png
      reference/
        angel-pixel-reference.png
```

예제는 스튜디오의 **기본 메시 + 두께가 있는 2D 윤곽 메시**로 구성한 블록아웃입니다. 원본 참조와 혼동하지 않도록 이미지 출처/대체 여부를 각 버전 README에 기록합니다.
